# 🗺️ Дорожная карта развития — «...В ритме дыхания...» (`Breathe Rhythm`)

Этот документ описывает план развития движка кинематографичной визуализации поэзии от текущей базы `v1.0` до полноценного интерактивного сборника `v1.3`.

---

## ✅ Текущая версия: `v1.0` — Ядро движка и библиотека текстовых акцентов
* Собственный парсер поэтической разметки (`BRParser`) с поддержкой пауз `{ms}`, темпа `<fast:X>` / `<slow:X>` и 22 эмоционально-смысловых акцентов (`BRAccentsMask`, `BRAccentsParticle`, `BRAccentsSyllabic`, `BRAccentsSimple`).
* Адаптивный `Canvas 2D` рендерер с Retina-чёткостью (`DPR`), автоматическим подбором масштаба шрифта и плавным скроллингом.
* Нативные Веб-Компоненты (`<ui-app>`, `<breathe-rhythm>`, `<ui-overlay>`, `<ui-toolbar>`, `<ui-button>`, `<ui-logo>`, `<ui-subtitle>`, `<ui-icon>`) без сторонних фреймворков.
* Модульная архитектура стилей на `Sass` и автоматизированная сборка (`TypeScript` + `esbuild` + `Dart Sass`) с валидацией CSS-токенов.

### 🔨 В завершении ветки `v1.0`:
- [ ] **Акценты разрушения и гашения слова при уходе в архив (`BRAccentsDestroy`)**:
    - [ ] `<scatter>` — рассыпание напечатанного слова на гаснущие частицы при переходе строки в архив.
    - [ ] `<wash>` — мягкая световая волна гашения, смывающая слово.
    - [ ] `<erase>` — стирание слова диагональными штрихами ластика.

## 🚀 Релиз `v1.1` — Публичный сборник, SEO-генерация и автовоспроизведение
*Цель: запуск живого поэтического пространства для читателей и поисковых систем.*

- [ ] **Нормализация разметки и расширение парсера (`BRParser.normalize`)**:
    - [ ] Приоритет внешнего тега при вложенности однотипных акцентов.
    - [ ] Запрет вложенности одноимённых тегов атмосферы и курсора; поддержка пауз `{ms}` и однократных эффектов внутри акцентов.
    - [ ] Очистка неполноценных тегов без параметров (`[atm]`, `[cur]`).
- [ ] **Хранение данных (`JSON5` → `JSON`)**:
    - [ ] Отдельные файлы стихотворений в формате `.json5` с автоматической компиляцией в чистые `.json` при сборке.
    - [ ] Асинхронная загрузка произведений движком.
- [ ] **Титульный слой произведения на холсте**:
    - [ ] Выделенное пространство и плавная анимация появления названия стихотворения и имени автора.
- [ ] **Генерация статических SEO-страниц (SSG) и клиентский SPA-роутинг**:
    - [ ] HTML-шаблон с семантическим текстом произведения (`{%content%}`) и навигацией (`{%navigation%}`).
    - [ ] Генерация `navigation.json`, отдельных `.html` страниц для каждого стихотворения, а также страниц `index.html` и `404.html` с данными об авторе.
    - [ ] Бесшовный переход между стихотворениями по URL без перезагрузки страницы.
- [ ] **Режим непрерывного автовоспроизведения**:
    - [ ] Компонент-контрол 5-секундного обратного отсчёта над холстом + анимация перехода (световая спираль из многоточий), стирающая предыдущий холст.
    - [ ] Случайный выбор следующего стихотворения без повторов в рамках сессии.
    - [ ] Переключатель автоплея в контроле и горячая клавиша `A` с всплывающим уведомлением.

## 🎨 Релиз `v1.2` — Каталог стихотворений и драматургия сцены
*Цель: удобная навигация по сборнику и многослойная визуальная атмосфера.*

- [ ] **Навигация по сборнику (`<nav>`) и диалог «Об авторе»**:
    - [ ] Выезжающая справа панель со списком стихотворений (`1/3–1/2` ширины на десктопе, `100dvw` на мобильных экранах) с живым поиском по названию.
    - [ ] Кнопка вызова каталога поверх всех слоёв и модальное окно информации об авторе.
- [ ] **Трёхслойный холст (`Scene` → `Blur` → `Active Text`)**:
    - [ ] Нижний слой эффектов сцены под полупрозрачным архивным текстом.
    - [ ] Средний слой `Blur`-подложки под активной строфой для мягкого отделения текста от фона.
    - [ ] Верхний слой активной печати, текстовых акцентов и курсора.
- [ ] **Курсор каретки (`[cur: ...][/cur]`)**:
    - [ ] Отрисовка одиночного символа или цикличной покадровой смены символов каретки при печати.
- [ ] **Система атмосфер (`[atm: ...][/atm]`) и библиотека эффектов сцены**:
    - [ ] Цикличные очереди эффектов с настраиваемой паузой (`delay`, по умолчанию `800 мс`), прерывание цикла однократным эффектом с затуханием и автоматическим возобновлением.
    - [ ] Движок пространственных траекторий (зеркальные области с временным сдвигом, предотвращение наложений, хаотичные куртинки и однонаправленные потоки):
        - **Погода и стихии**: дождь (штрихи), капли на стекле, круги на воде (лужа), облака, туман, аромат, порывы ветра, снег, морозные узоры (стужа), фонтаны искр и воды.
        - **Времена года и флора**: осенние листья, весенние лепестки, летние ветки с листьями, распускающиеся куртинки цветов, спиральные лозы плетистых роз.
        - **Атмосферные детали (правый нижний угол)**: чашка кофе со струящимся ароматом, штрихующийся лист блокнота, спящий/умывающийся котан.

## 🎬 Релиз `v1.3` — Слайдовый режим, полноэкранное погружение и каллиграфия
*Цель: кинематографичная подача крупных произведений и оптимизация производительности.*

- [ ] **Полноэкранный режим (`Fullscreen API`)**:
    - [ ] Автоматический вход при старте воспроизведения (`Play`), выход при сбросе (`Reset`) или изменении размера окна.
    - [ ] Сохранение полноэкранного режима при ручной паузе и уважение к ручному выходу пользователя.
- [ ] **Слайдовый режим визуализации строф (Портрет и Ландшафт)**:
    - [ ] Расчёт размера шрифта по самой длинной строфе и самой длинной строке с гарантированными отступами `≥ 30px`.
    - [ ] **Портретный режим**: 2 строфы по вертикали, активная в центре, плавный уход вверх с уменьшением масштаба до `0.8`.
    - **Ландшафтный режим**: 3 строфы по горизонтали, активная в центре, плавный уход влево с уменьшением масштаба до `0.8`.
- [ ] **Пост-финальный слайдинг по строфам**:
    - [ ] Автоперемотка к первой строфе после финальной вспышки текста (при отключённом автовоспроизведении) с акцентом на центральном слайде.
    - [ ] Внешние неоновые контролы перемотки `<<` / `>>` по краям экрана и навигация стрелками клавиатуры.
- [ ] **Каллиграфический режим и оптимизация загрузки**:
    - [ ] Посимвольная отрисовка пером для стихотворений в высоком стиле под курсивные и рукописные шрифты.
    - [ ] Динамическая подгрузка модулей эффектов сцены по требованию (`Lazy Loading`).
